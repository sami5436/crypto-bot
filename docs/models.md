# 📖 models.py

Data classes and enums used throughout the bot.

---

## Enums

### `Side`
Order side for spot trading.
```python
Side.BUY   # Buy order
Side.SELL  # Sell order
```

### `PositionSide`
Position direction for futures.
```python
PositionSide.LONG   # Profit when price goes UP
PositionSide.SHORT  # Profit when price goes DOWN
PositionSide.NONE   # No position
```

### `Signal`
Trading signals generated by strategies.
```python
Signal.NONE         # No action
Signal.BUY          # Spot buy
Signal.SELL         # Spot sell
Signal.LONG         # Open long position (futures)
Signal.SHORT        # Open short position (futures)
Signal.CLOSE_LONG   # Close long position
Signal.CLOSE_SHORT  # Close short position
```

## Dataclasses

### `Position`
Represents a spot trading position.

| Field | Type | Description |
|-------|------|-------------|
| `symbol` | `str` | Trading pair |
| `qty` | `float` | Position size |
| `entry_price` | `float` | Entry price |
| `side` | `Side` | BUY or SELL |
| `stop_loss` | `float` | Stop loss price |
| `take_profit` | `float` | Take profit price |
| `entry_time` | `datetime` | When position opened |

---

### `FuturesPosition`
Represents a leveraged futures position.

| Field | Type | Description |
|-------|------|-------------|
| `symbol` | `str` | Trading pair |
| `side` | `PositionSide` | LONG or SHORT |
| `size` | `float` | Position size in base currency |
| `entry_price` | `float` | Entry price |
| `leverage` | `int` | Leverage used |
| `margin` | `float` | Margin collateral |
| `liquidation_price` | `float` | Price at which position is liquidated |
| `stop_loss` | `float` | Stop loss price |
| `take_profit` | `float` | Take profit price |
| `entry_time` | `datetime` | When position opened |
| `unrealized_pnl` | `float` | Current unrealized PnL |
| `funding_paid` | `float` | Total funding paid |

#### Methods

| Method | Returns | Description |
|--------|---------|-------------|
| `calculate_pnl(price)` | `float` | Calculate PnL at given price |
| `calculate_roe(price)` | `float` | Calculate Return on Equity |
| `is_liquidated(price)` | `bool` | Check if price triggers liquidation |

---

### `Trade`
Represents an executed trade.

| Field | Type | Description |
|-------|------|-------------|
| `timestamp` | `datetime` | When trade executed |
| `symbol` | `str` | Trading pair |
| `side` | `str` | "buy", "sell", "long", "short", etc. |
| `qty` | `float` | Quantity traded |
| `price` | `float` | Execution price |
| `fees` | `float` | Fees paid |
| `realized_pnl` | `float` | Profit/loss realized |
| `balance_after` | `float` | Balance after trade |
| `leverage` | `int` | Leverage used (futures) |
| `margin_used` | `float` | Margin used (futures) |
| `is_liquidation` | `bool` | Was this a liquidation? |

---

### `KillSwitchStatus`
Status returned by kill switch checks.

| Field | Type | Description |
|-------|------|-------------|
| `should_halt` | `bool` | Should trading stop? |
| `reason` | `str` | Why trading was halted |

---

### `FundingPayment`
Records a funding rate payment.

| Field | Type | Description |
|-------|------|-------------|
| `timestamp` | `datetime` | When payment occurred |
| `symbol` | `str` | Trading pair |
| `position_side` | `PositionSide` | LONG or SHORT |
| `position_size` | `float` | Position size |
| `funding_rate` | `float` | Funding rate applied |
| `payment` | `float` | Amount paid/received |
